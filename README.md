# Blake H Ferrin - Professional Portfolio

## Project Overview

This project is a responsive, single-page professional portfolio created for my Web Design assignment in CS 3810 at Weber State University.

The website showcases my background as a Software Development Student, technical skills, and selected programming projects.

The portfolio uses a modern minimalist design focused on simplicity, readability, accessibility, and responsive layouts.

## Featured Projects

The portfolio highlights three software development projects:

1. **WildCal** - A university event calendar application designed to help students discover campus events, manage RSVPs, and connect with student organizations.
2. **Learning Management System** - A database design project modeling students, instructors, courses, assignments, and submissions.
3. **Tic-Tac-Toe** - A desktop game developed using C# and WPF, featuring player turns, game logic, and win detection.

Each project card includes a link to an external project resource.

## Running the Project Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Ensure `styles.css` is located in the same directory as `index.html`.

No additional dependencies or installations are required.

## Responsive Design

The website uses a mobile-first approach with the following breakpoints:

| Device | Screen Width | Project Layout |
|---|---|---|
| Mobile | Below 600px | Single column |
| Tablet | 600px–899px | Two columns |
| Desktop | 900px and above | Three columns |
